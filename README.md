# Smart Campus 🎓

Smart Campus is a comprehensive digital solution designed to streamline university operations, enhance student engagement, and provide a centralized platform for campus management. Built by Group 200 for IT3030 PAF 2026.

## 🌟 Key Features
- **Facility Management & Bookings:** Browse and book campus facilities through a dynamic catalogue.
- **Support & Ticketing System:** Report issues and track support tickets directly from the dashboard.
- **Kuppi Sessions (Peer Tutoring):** Schedule and discover student-led academic support sessions.
- **Lost & Found Portal:** Report lost items and claim found properties within the campus.
- **Admin Dashboard:** Comprehensive overview for administrators to manage facilities, tickets, and user roles.
- **Real-time Notifications:** Email notifications for booking updates and ticket statuses.

## 💻 Tech Stack

### Frontend
- **React.js (Vite)**
- **Firebase** (Authentication)
- **React Router**
- **Axios** (API Communication)
- **Framer Motion** (Animations)
- **Recharts** (Data Visualization)
- **jsPDF** (Report Generation)

### Backend
- **Java Spring Boot** (v3.3.4)
- **Spring Security & OAuth2**
- **Spring Data MongoDB**
- **Spring Boot Mail**
- **Lombok**
