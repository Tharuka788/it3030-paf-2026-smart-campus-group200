# Smart Campus 🎓

Smart Campus is a comprehensive digital solution designed to streamline university operations, enhance student engagement, and provide a centralized platform for campus management. Built by Group 200 for IT3030 PAF 2026.

## 🌟 Key Features
- **Facility Management & Bookings:** Browse and book campus facilities through a dynamic catalogue.
- **Support & Ticketing System:** Report issues, request maintenance, and track support tickets directly from the dashboard.
- **Admin Dashboard:** Comprehensive overview for administrators to manage facilities, review tickets, and oversee system operations.
- **Real-time Notifications:** Automated email notifications for booking updates, ticket statuses, and important alerts.
- **User Authentication:** Secure login and role-based access control for students, staff, and administrators.

## 💻 Tech Stack

### Frontend
- **React.js (Vite)**
- **Firebase** (Authentication)
- **React Router** & **Axios**
- **Framer Motion** & **Recharts**

### Backend
- **Java Spring Boot** (v3.3.4)
- **Spring Security**
- **Spring Data MongoDB**
- **Spring Boot Mail**
